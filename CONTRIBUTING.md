# Contributing

Thanks for wanting to help. Issues and pull requests are welcome at [stagdhq/stagd](https://github.com/stagdhq/stagd).

- **Building and testing:** [docs/development.md](docs/development.md). `go tool task check` is what CI runs; please run it before opening a pull request.
- **Commit subjects** become the release notes, so write them for users: `feat:` or `fix:` for what they notice. See [docs/releasing.md](docs/releasing.md#changelog).
- **Security issues** go privately to security@stagd.dev, never in a public issue: see [SECURITY.md](SECURITY.md).
